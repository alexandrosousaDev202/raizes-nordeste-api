# 🍔 API Raízes do Nordeste - Projeto Multidisciplinar

Solução de Back-end desenvolvida em PHP com Yii2 para a rede de lanchonetes "Raízes do Nordeste". Este projeto atende aos requisitos de multicanalidade, controle de estoque distribuído por unidades e integração com mock de pagamento, conforme escopo da disciplina.

## 🛠️ Tecnologias e Requisitos
*   **PHP:** >= 8.1
*   **Framework:** Yii2 (Basic Template)
*   **Banco de Dados:** PostgreSQL >= 13
*   **Gerenciador de Dependências:** Composer

## ⚙️ Configuração do Ambiente

**1. Clone o repositório e instale as dependências:**
```bash
git clone [https://github.com/alexandrosousaDev202/raizes-nordeste-api.git](https://github.com/alexandrosousaDev202/raizes-nordeste-api.git)
cd raizes-nordeste-api
composer install
